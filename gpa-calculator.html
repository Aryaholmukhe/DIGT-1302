Manual GPA Entry

Use this form to enter your course names, course percentages, and credit hours. In the final interactive version, JavaScript will convert the percentages into GPA values and calculate a weighted overall result automatically.

If you want to review the GPA scale and see a worked example first, visit the GPA Overview page.

How to Use This Calculator

  1. Enter each course name so your GPA result is easy to read.
  2. Type the course percentage you currently have or expect to finish with.
  3. Add the correct credit hours for each course.
  4. Use the GPA Overview page if you need help understanding the conversion scale.

What users will see in the final version

  • Total weighted GPA points
  • Total credit hours
  • An overall GPA summary message
