What This Profile Will Support

Planned account features

  • Store the student name, number, and university contact details.
  • Save default target grades so each course starts with a clear goal.
  • Connect profile settings to dashboard summaries and GPA estimates.
  • Support reminder preferences for assignments, exams, and GPA review habits.

Privacy note

GradeGuard is planned as a client-side application. In later phases, profile details may be stored locally in the browser for convenience, but this Phase 1 version does not collect or permanently save user information.
